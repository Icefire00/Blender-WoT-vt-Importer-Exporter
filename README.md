# Blender-WoT-vt-Importer-Exporter
A blender plugin for import/export WoT Bigworld's .vt

This is a blender plugins for importing and exporting directly into/from blender
Thank to atacms for his work where .vt format is referred from https://github.com/atacms/wot-vt-converter 
I just create this plugin to ease my WoT mod workflow in Blender 5.0

Installation:
  In Blender
  Edit > Preferences > Add-ons > Install...
  Select the import and export .py file, then enable.

  Note: import and export is 2 separate installations, you can choose to install separately.  

Usage:
Import:
  File > Import > BigWorld VT Collision (.vt)
  Select the .vt file to import from

Export:
  Select the mesh object(s) you want to export, then:
  File > Export > BigWorld VT Collision (.vt)
